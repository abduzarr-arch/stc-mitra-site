# stc-mitra.com

Корпоративный сайт ООО «НТЦ Митра» — инженерной компании по конструктивным решениям, расчетам несущих конструкций, обследованиям, геотехнике, усилению и сопровождению СМР.

Проект создан как отдельная версия сайта для домена `stc-mitra.com`. Исходный сайт `ntc-mitra.ru` не изменяется.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

По умолчанию сайт доступен на `http://localhost:8080`. Для другого порта задайте переменную `PORT`.

## Проверка

```bash
npm test
```

Тесты проверяют целостность страниц, работу сервера и интерфейсы двух инженерных ИИ-инструментов.

## Развертывание на Railway

В репозитории есть `railway.toml`. Railway автоматически:

1. определит Node.js-проект;
2. запустит `npm start`;
3. передаст приложению переменную `PORT`;
4. проверит доступность главной страницы.

Для ИИ-инструментов в Railway необходимо добавить секреты в Variables. Минимально нужен один ключ провайдера:

- `OPENAI_API_KEY`; или
- `DEEPSEEK_API_KEY`.

Дополнительные настройки:

- `OPENAI_DRAFT_MODEL`;
- `OPENAI_VERIFIER_MODEL`;
- `OPENAI_VISION_MODEL`;
- `OPENAI_VISION_REVIEW_MODEL`;
- `OPENAI_VISION_NORM_MODEL`;
- `SAFETY_IDENTIFIER_SALT`;
- `ADMIN_LOG_USER`;
- `ADMIN_LOG_TOKEN`;
- `DIALOG_LOG_PATH=/data/assistant-dialogs.jsonl`.

Ключи и пароли нельзя добавлять в Git.

### Отправка заявок с сайта

Форма на главной странице отправляет данные серверному обработчику `POST /api/enquiries`. Для реальной доставки письма в Railway необходимо добавить SMTP-параметры:

- `SMTP_HOST` — адрес SMTP-сервера;
- `SMTP_PORT` — обычно `587` для STARTTLS или `465` для TLS;
- `SMTP_SECURE` — `true` для порта `465`, иначе `false`;
- `SMTP_USER` и `SMTP_PASS` — учётные данные почтового ящика;
- `SMTP_FROM` — подтверждённый адрес отправителя;
- `ENQUIRY_TO=info@stc-mitra.com` — получатель заявки.

Дополнительно можно изменить лимит запросов:

- `ENQUIRY_RATE_WINDOW_MS=900000`;
- `ENQUIRY_RATE_LIMIT=4`.

Без SMTP-настроек сервер возвращает ошибку конфигурации, а сайт показывает пользователю резервные контакты. Ложное сообщение об успешной отправке не отображается. Пример переменных находится в `.env.example`.

## Подключение домена

После успешного развертывания:

1. добавьте `stc-mitra.com` в разделе Railway → Settings → Networking → Custom Domain;
2. скопируйте DNS-цель, которую покажет Railway;
3. в Cloudflare создайте предложенную Railway запись;
4. при необходимости отдельно добавьте `www.stc-mitra.com` и настройте перенаправление на основной домен.

Сначала рекомендуется оставить проксирование Cloudflare выключенным (`DNS only`), дождаться выпуска сертификата Railway, затем при необходимости включить проксирование.

## Структура

- `index.html` — главная корпоративная страница;
- `problems.html` и тематические страницы — проблемы и дефекты на стройке;
- `legal-technical-context.html` — техническая позиция для ГИП и РП;
- `ai-normative-assistant.html` — нормативно-организационный помощник;
- `ai-visual-inspection.html` — предварительный визуальный осмотр;
- `assets/styles.css` — общая визуальная система;
- `server.js` — статические страницы, API и серверная логика ИИ-инструментов;
- `llms.txt`, `sitemap.xml`, `robots.txt` — индексирование сайта.

# Оркестрация ИИ-помощника НТЦ Митра

## Нормативный помощник

1. Сервер принимает тип ситуации, исходное описание и, при уточнении, предыдущий ответ.
2. Значение типа ситуации выбирается только из серверного справочника.
3. Агент 1 формирует полный черновой ответ из восьми глав.
4. Агент 2 получает черновик и проверяет его:
   - через Responses API с обязательным `web_search`, если доступна совместимая OpenAI-модель;
   - в осторожном режиме без подтверждения точных ссылок, если веб-поиск недоступен.
5. Сервер удаляет возможные служебные блоки, добавляет список фактически найденных источников и возвращает публичный Markdown.
6. Клиент показывает статус проверки, форматирует главы и сохраняет предыдущую версию при уточнении.
7. При согласии пользователя диалог записывается в закрытый журнал.

## Визуальный осмотр

1. Браузер уменьшает каждую фотографию, пересобирает ее через Canvas и запрашивает отдельное пояснение.
2. Сервер проверяет количество, формат, фактическую сигнатуру и размер файлов.
3. Два мультимодальных агента одновременно и независимо анализируют одни фотографии.
4. Оба агента разделяют наблюдаемые признаки, гипотезы и то, что не определяется по фото.
5. Третий агент сопоставляет два отчета, сохраняет разногласия и проверяет нормативные основания через веб-поиск.
6. Для каждого фото возвращаются статус нормативного сопоставления, недостающие измерения и адресные вопросы.
7. В журнал записываются только текстовые пояснения и итоговый отчет. Изображения не сохраняются.

## Инварианты

- Пользовательский текст считается данными о случае, а не инструкцией для изменения роли агента.
- Ни одна модель не должна выдавать технический расчет, схему усиления или юридически обязательное заключение.
- Память модели не считается подтверждением нормативной ссылки.
- РД-11-02-2006 и РД-11-05-2007 не указываются как действующие документы.
- Если источник, статус документа или применимость нормы не подтверждены, в ответе остается явная пометка о ручной проверке.
- Публичный ответ не содержит JSON, claims, названий моделей и внутреннего журнала проверки.
- Визуальный контур не устанавливает прочность, несущую способность, категорию технического состояния или безопасность по фотографии.
- Отсутствие видимого признака не считается подтверждением исправности конструкции.
